## Bug 1: 0.12 / 7.16 — PRIVATE_AI privacy leak

**File 1**: `clanmind-frontend/src/features/chat/chatSelectors.ts`, line ~49

PROBLEM: The PRIVATE_AI case returns `true` for EVERY PRIVATE_AI message without verifying the local user participates. A foreign user's private AI body gets cached AND rendered in the current user's PRIVATE_AI view.

FIX: Add a sender_id / request_id check. The PRIVATE_AI case must verify the local user is the sender or the requester before returning true.

Read the file first. Look at how PRIVATE_PAIR is gated (it's correct) and apply the same pattern to PRIVATE_AI.

**File 2**: `clanmind-frontend/src/features/realtime/dispatch.ts`, line ~250

PROBLEM: `recipientId === 'ai'` admits ANY user's PRIVATE_AI event into any device's cache.

FIX: Add a dispatch gate — only admit the event if the local user is the sender or the requester.

Per §56–§58, §2.26, §190, §284.
